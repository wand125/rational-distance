# 頂点を中心とする円の上の 4 距離点

2026年11月7日、mathematics-52。

4 距離点 P は原点からの距離 r = |P| が有理数なので、円 |P| = r の上にある。正方形の対称性で 4 頂点はどれも同じに扱えるので、高さ max(|分子|, 分母) ≤ H の r の円をすべて調べると、「どこかの頂点までの距離の高さが H 以下」の 4 距離点がすべて調べ尽くされる。

## 式

P = r((1 − t²), 2t)/(1 + t²) とおく（t = ∞ は P = (−r, 0)）。

- N₂ = (r − 1)² + (r + 1)²t²
- N₃ = (r² + 1)(1 + t²) − 4rt
- N₄ = (r² + 2)(1 + t²) − 2r(1 − t²) − 4rt

(1,0)、(0,1)、(1,1) への距離の 2 乗は N_j/(1 + t²) になる。4 つの多項式 1 + t²、N₂、N₃、N₄ はどれも正定値で、根は Q(i) に入る。条件を満たす曲線は種数 9 で、その商は種数 1 の曲線 6 つ（(1 + t²)N_j と N_aN_b）と種数 3 の曲線 1 つである。

## 方法

**共通の平方類による降下（`circ_cdesc2`）。** 4 距離点の t では 4 つの値がどれも同じ平方類 d·□ に入る（d は正で平方因子を持たない）。d の素因数は、値の組どうしの終結式の素因数（集合 S）に限られる。S の素数の積でできるすべての d について、ある素数 p ≤ 2000 で、4 つの d·f(t) が同時に Q_p の平方になる t ∈ P¹(Q_p) がないことを示せれば、その円に 4 距離点はない。

- p 進の判定は、円板を細かく分けて調べる（`lm_disc`）。円板の上で値の平方類が定まったときだけ「点がない」とし、決まらない円板は「点がありうる」として扱う。証明に使うのは「点がない」の判定だけである。
- 判定は d の Q_p での平方類だけで決まる。そこで、各素数で 4 通り（p = 2 では 8 通り）の代表を調べ、d の一覧と照らし合わせる。

**階数 0 の商（`circ_verdict`）。** 種数 1 の商のどれかで ellrank の上界が 0 になり、見つけた点の数（無限遠の点を含む）がねじれ群の位数と一致すれば、点の一覧は完全である。一覧の t を 4 条件で正確に調べる。

## 確かめ

- **実在の点で落とさないか**：総当たりで、(0,0) と、(1,1) か (1,0),(0,1) か (1,0),(1,1) に有理数の距離を持つ点を探した。その半径の円に、対応する頂点だけの降下をかけた。372 円とも点を落とさなかった（速い版では 254 円）。
- **落とした判定の確かめ**：別に書いた p 進の乱数で、落とした [d, p] の組（r = 13, 7/3, 5/12, 29/28 で合わせて 11,776 組）を調べた。点は 1 つも出なかった。乱数の側が点を拾えることも別に確かめた。
- **速い版と遅い版**：7 円で、判定も落とした d の数も一致した。
- **2 進の点の分布**：Q₂ 上の 4 距離点を乱数で探した。見つかった点では、どれも v₂(r) ≤ −2 だった。分母が 4 で割り切れない r の円がすべて p = 2 で落ちることと合っている。

### 方法の追加

**F₂ の一次方程式による数え上げ（`circ_cdesc3`）。** d の Q_p での平方類は、d の素因数の指数ベクトル（F₂ 上）の一次式になる。各素数で生き残る類を選んで連立方程式にし、矛盾するかを枝分かれで調べる。2^|S| 個の d を総当たりする `circ_cdesc2` と、高さ 30 の 554 円と重い 5 円で、判定も生き残る d の数も一致した。

**Q(i) の上の細かい降下（`qidesc.gp`）。** f_j = c_j(t − α_j)(t − ᾱ_j)（α_j ∈ Q(i)）とおく。有理点 t = a/b では、t − α_j の平方類は b·δ_j の形になる（δ_j ∈ Q(i)(S,2)、b ∈ Q^*）。未知数は次の 2 つである。

- δ_j の指数ベクトル（基底は i と、S の上の素イデアルの生成元）。
- 素数ごとの b の Q_p^*/Q_p^{*2} での類。

条件は次の 2 つである。

- 大域：c_j N(δ_j) ≡ c_1 N(δ_1)（Q^*/Q^{*2} で）
- 局所：p ≤ 400 の S の素数ごとに、t ∈ P¹(Q_p) での t − α_j の類と一致する

局所の類は、ヒルベルト記号を局所の基底に当てて座標にする。局所の像は、根を含む円板や決まらない円板を「何でもよい」とするので、像を大きめに取っている。そのため「解なし」の判定は証明になる。探索では、素数ごとに局所の未知数を消して重複をまとめる。そのうえで、候補の少ない素数から選び、選ぶたびに残りの候補を整合するものに絞る。

## 細かい降下の誤りと直した版（2026年11月8日）

### 誤り

`qi_canon` が、局所の未知数を消すと式が 1 つも残らない部分（条件なし）を、矛盾と同じ印で返していた。gp では `[] == 0` が真になるため、条件なしの部分が捨てられていた。そのため局所の像が小さくなり、点を持つ曲線まで「解なし」としていた。

見つけたのは、大きい素数を入れた段 3（`st3_11072315/`）の確かめである。(1,1) の組 [1,4] で、実在の点を持つ 4 円（r = 13/20, 35/13, 35/19, 37/21）を誤って落とした。この段 3 の結果はすべて捨てた。

### 直した版での確かめ

### 大きい素数

p > 400 では、根を含む子の円板だけを細かく調べる。ほかの子はまとめて「根の成分は p^k × 単数（類は何でもよい）、決まらない成分は何でもよい」とする。局所の像を大きめに取るので、「解なし」は証明のままである。中くらいの素数（50 < p ≤ 400）でまとめると、正しく落ちていた円を落とせなくなったので、まとめるのは p > 400 だけにした。

## 未決 163 円の Mordell–Weil ふるい（2026年11月9〜10日）

### 方法

**Mordell–Weil ふるい（`mwsieve.gp`）。** 有理点を 1 つ持つ種数 1 の商 v² = f_a f_b（4 次式）を選び、その点を使って Weierstrass 形 E に写す（Washington の定理 2.17）。4 距離点の t は E(Q) の点 P = Σ n_i G_i + T に対応する（G_i は生成元、T はねじれ）。

- 整数 M を素数の鎖に沿って大きくし、類 (n mod M, T) を絞る。
- 生成元の位数がすべて M を割る素数 ℓ で、類の点を E(F_ℓ) で計算し、t mod ℓ に戻す。
- 残りの 2 つの値 f_a f_c（c は a, b 以外）がどちらも ℓ で平方でも 0 でもなければ、その類を落とす。t = ∞ は最高次の係数で判定する。
- 判定が決まらない場合（y = 0 の点、ℓ が分母に入る場合など）は残す。そのため「全部の類が落ちた」は証明になる。
- 生成元は ellrank（effort 2〜4、階数 1 では ellheegner も）で求め、ellsaturation(·, 100) で飽和させる。ellrank の下界と上界が一致し、生成元の数が階数と等しく、高さの行列が正則なときだけ使う。

**確かめ。**

- 正の対照：本物の判定の代わりに、既知の有理点 t₁ で平方になる乱数の 4 次式 2 つを置く。ふるいが全部を落とせば誤りである。誤って落とした例は 0（mw4、146 円）。
- 照合（`mw_cross`）：小さい n の点を実際に計算し、どの素数でも「点の直接の判定が通る ⇒ その類も残る」を確かめた。違反は 0。

**第 2 系（Sage・eclib、`mw_sage.py`）。** ふるいが実際に使った曲線・生成元・ねじれの位数・4 次式を書き出し（`MW_DUMP`）、PARI の ellrank・ellsaturation を使わずに確かめる。

- 4 次式の不変量 I, J から作った曲線と j 不変量が一致する。
- 生成元が E の上にある。ねじれの位数が一致する。
- 飽和の指数が 1（Sage の saturation、max_prime = −1：上限は高さから計算する）。
- 階数：mwrank（proof=True）。mwrank が決められない組は、根数と誤差の範囲つきの L(E,1)（または L′(E,1)）が 0 でないことを確かめ、Gross–Zagier–Kolyvagin の定理で階数 0（または 1）とする（`mw_sage3.py`、Sage の `lseries().at1`・`deriv_at1`、項の数 4√N + 10）。

**階数 0 の商（`rank0L.txt`）。** 組 [1,2] の商が階数 0 なら、4 次式の有理点は既知の 4 点（t = 0, ∞）だけで、どれも 4 距離点ではない。階数 0 は、誤差の範囲つきの L(E,1) ≠ 0 で示した（最初は Sage の L1_vanishes で、Manin 定数が 2 以下という条件つきだった）。ねじれの位数 4 と j 不変量は Sage でも一致した。ellrank の上界は 2 だった（Sha[2] が自明でない）。

**時間を延ばした細かい降下（`st7_11090640/`）。** 900 秒で終わらなかった 32 円の 4 因子すべての降下を、上限を延ばして回した。32 円すべてを除外した。

## 未決 9 円を閉じる（2026年11月11〜12日）

11/10 の時点で未決だった 9 円（607/120、863/360、967/360、167/480、727/720、343/960、887/960、911/960、383/984）を、2 つの方法で閉じた。これで高さ ≤ 1000 の円はすべて除外した。

### Q(i) の上で階数 0 の商（5 円、`qirank0.gp`、`qi_11111000/`）

組 3 の商 C: v² = f(t) の 4 次式は、根を Q(i) に持つ（1 + t²、N₂、N₃、N₄ の根はどれも Q(i) にある）。そのため C は K = Q(i) の上で楕円曲線 E と同型になる。

- **qi_rank0**（607/120、863/360、967/360）：ヤコビアン J と、その −1 によるひねり J⁻¹ の階数がどちらも 0 なら、E(K) は有限である。E(K) のねじれを並べ、C に戻して、有理数の t を全部取り出す。
- **qi_rank0b**（727/720、911/960、と上の 3 円）：J(Q) の階数だけが 0 の場合。共役は E(K) に σ(Q) = τ(Q) + c の形で働く。有理点は 2Q = S + c（S は τ で固定されるねじれ点）を満たすので、その半分を全部試し、σ で固定されるものだけを残す。
- どの円でも、有理数の t は 4 距離点にならなかった（`qi_all.txt`）。
- 階数 0 は、誤差の範囲つきの L(J,1) ≠ 0（qi_rank0 では L(J⁻¹,1) も）から、Kolyvagin の定理で示した。Q(i) の上のねじれの位数も Sage で照合した（`sage_L.txt`）。PARI の ellrank は 911/960 で J の上界を決められなかったが（[0, 2]）、L(J,1) = 2.737（誤差 1.8×10⁻⁶）で階数 0 になる。

### 生成元を見つけてからの Mordell–Weil ふるい（4 円）

残る 4 円は、組 1 の商のヤコビアンの階数が 1（根数 −1）で、ellrank が生成元を返さなかった。BSD から見込んだ生成元の高さは 80〜130 で、点の探索では届かない。生成元は次の 3 通りで求め、どれも ellsaturation で飽和させてからふるいに渡した。

| 円 | 生成元の求め方 | 高さ | ふるいの記録 |
|---|---|---:|---|
| 343/960 | Heegner 点（ellheegner、3.4 時間） | 128.96 | `mwh_11111030/` |
| 167/480 | 同種類の曲線の 2 被覆（ell2cover）の点 | 79.61 | `mwc_11120955/` |
| 383/984 | 同種類の曲線の 2 被覆の点 | 86.93 | `mwc_11120955/` |
| 887/960 | 2 被覆を 2 つの 2 次式に割って作る 4 被覆の点（`foursearch.gp`） | 128.86 | `mw4d_11121234/` |

- **2 被覆（mode 3、`mw_cover_iso`）：** 同種類の曲線を BSD の定数 Ω∏c_p/#T² の大きい順に並べ、ell2cover の 2 被覆の有理点を探す。見つけた点を同種写像（ellisomat）で元の曲線に戻す。
- **4 被覆（mode 4、`foursearch.gp`）：** 有理 2 ねじれをすべて持つ曲線では、2 被覆の 4 次式 g が g = q₁q₂（2 次式）と割れる。点では q₁ = d w₁²、q₂ = d w₂² となる（d は 2·lc(q₁)·lc(q₂)·Res(q₁,q₂) の素因数で作る平方因子のない数）。各 d について円錐曲線 q₁ = d w² をパラメータ表示し、d·q₂ に代入した 4 次式（4 被覆）を最小化（hyperellminimalmodel）と簡約（根から作る共変の 2 次形式の Gauss 簡約）をしてから点を探す。判別式が最小のものから 10⁵ 倍以内だけを探す（局所可解な 4 被覆は曲線の水準まで最小化される）。
  - 確かめ：生成元が分かっている 167/480 と 383/984 で、同じ高さ（79.61、86.93）の点を 1 秒程度で再現した。
  - 887/960 では、2 被覆の点の探索（高さ 7.29×10⁶ まで、2 時間）で見つからなかった生成元を、4 被覆の高さ 10⁶ までで得た（d = −64751 と 1638289、各 2 点）。
  - ell2cover の返す代表は PARI の版で違う（Intel の 2.15.4 と母艦の 2.17.2）。2.15.4 の代表の 4 被覆では 10⁶ まで点が出なかったので、生成元は 2.17.2 で求めて `gen_887_960.gp` に書き、ふるいはそれを使った（mode 5、`mw_given`：同じ最小モデルの上にあることと無限位数であることを確かめる）。
- ふるい自体は前と同じ（正の対照 2、誤って落とした例 0、照合の違反 0）。
