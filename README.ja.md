# 単位正方形の 4 頂点への有理距離

単位正方形の 4 頂点 (0,0)、(1,0)、(0,1)、(1,1) への距離がすべて有理数になる点 P は、平面上にあるか。これは未解決の問題である。このリポジトリには、そのような点を見つけなかった 2 つの計算を収める。どちらも問題を解いてはいない。

英語版：[README.md](README.md)。

## 結果

**1. 全平面、分母に上限（全数探索、`all-plane/`）。**
座標の最小共通分母が 10,000,000 以下の点で、4 頂点への距離がすべて有理数になるものは、全平面（正方形の内部と外部）にない。

- 探索は、必要な算術条件で候補を絞り、残った候補をすべて正確な整数演算で組み立て直す。
- 3 頂点への距離が有理数になる点は書き出し、Python の整数で検査し直した。分母の幅 2,000,000 の区間ごとに、およそ 100 個出た。
- これは有限の計算で、存在しないことの証明ではない。

**1b. 有界な箱、より大きい分母（相手の探索、`partner-search/`）。**
箱 [−9, 10]² の中に、共通分母 10¹¹ 以下のそのような点はない。

- |C| ごとに C² の約数からピタゴラスの相手を並べ、組を試す。相手を列挙する考えは GitHub の Mulatram-UwU/rational-distance-problem（内部だけ）から取り、符号つきの座標に広げて Rust で書き直した。
- 小さい箱では独立の総当たりと完全に一致し、内部の件数は N = 10⁴〜10⁷ でそのリポジトリの公表値と一致した。
- N = 10⁹、10¹⁰、10¹¹ の CPU 秒は 11,957、160,343、1,836,020。これも有限の計算である。

**2. 頂点を中心とする円（円ごとの証明、`circles/`）。**
そのような点は、ある頂点 V を中心とする有理数の半径 r の円 |P − V| = r の上にある。正方形の対称性から V = (0,0) としてよい。高さ max(|分子|, 分母) ≤ 1000 の r ≠ 1 の円を、すべて調べた（608,382 円）。そのすべてについて、4 頂点への距離がすべて有理数の点が円の上にないことを示した。r = 1 は手で除外した。

| 方法 | 除外した円 |
|---|---:|
| 共通の平方類による降下と p 進の局所判定（p ≤ 2000） | 606,491 |
| 種数 1 の商が階数 0 → 有理点をすべて並べて正確に判定 | 588 + 7 |
| Q(i) の上の細かい 2 降下（素数 10⁶ まで） | 1,140 + 31 |
| 種数 1 の商の Mordell–Weil ふるい | 116 + 4 |
| 種数 1 の商が Q(i) の上で階数 0 → 点を正確に判定 | 5 |
| 未決 | 0 |

各円は、除外した最初の行で 1 回だけ数えた。Mordell–Weil ふるいで除外したのは全部で 151 円で、そのうち 31 円は細かい降下でも除外されている。「+ 4」と Q(i) の行は、最後に閉じた 9 円（r = 607/120、863/360、967/360、167/480、727/720、343/960、887/960、911/960、383/984）である。

### 円の証明が拠るもの

- **降下と局所判定。**
  - 「点がない」とするのは、局所の平方類が決まった場合だけである。決まらない円板は「点がありうる」として扱い、証明には「点がない」の判定だけを使う。
  - いくつかの頂点に有理数の距離を持つ実在の点がある円で確かめた（最初の降下は 372 円、細かい降下は 2,579 通り）。実在の点を落とした例はなかった。
  - 11/08 に見つかった誤りは直し、影響する判定をすべて計算し直した（`circles/README.ja.md`）。
- **Mordell–Weil ふるい。**
  - 生成元は PARI の `ellrank`（下界と上界が一致）で求め、飽和させた。
  - 最後の 4 円では、`ellrank` は階数 1 を示したが生成元を返さなかった（見込みの高さ 80〜130）。生成元は、Heegner 点（343/960）、同種類の曲線の 2 被覆の有理点（167/480、383/984）、2 被覆の 4 次式を 2 つの 2 次式に割って作る 4 被覆の有理点（887/960、`foursearch.gp`）で求めた。4 被覆の探索は、167/480 と 383/984 の既知の生成元を再現する。
  - 除外はどれも 3 通りで確かめた。点を仕込んだ正の対照、小さい倍数での直接の照合、独立の第 2 系（Sage と eclib）である。
  - 第 2 系では、j 不変量、ねじれ、高さの上限による飽和の指数 1、階数を確かめた。
  - 第 2 系の階数は mwrank で示した。mwrank が決められない場合は、根数と誤差の範囲つきの L(E,1) または L′(E,1) ≠ 0 から、Gross–Zagier–Kolyvagin の定理で示した。
- **階数 0 の商。** 「+ 7」の 7 円は、誤差の範囲つきの L(E,1) ≠ 0（Sage の `lseries().at1`）から、Kolyvagin の定理で階数 0 とした。
- **Q(i) の上で階数 0。** これらの商の 4 次式は根を Q(i) に持つので、曲線は Q(i) の上の楕円曲線になる。ヤコビアン J の Q 上の階数が 0 なら（3 円では −1 によるひねりも 0）、Q(i) の上のねじれとガロアの作用から有理点を正確に求められる。階数は誤差の範囲つきの L(J,1) ≠ 0 による。
- **r = 769/360 の 1 円**だけは、階数を 1 つの系にしか頼っていない。ふるいの曲線は階数 2 で、その上界は PARI の `ellrank` だけによる。mwrank は、同種類のどの曲線でも上界を決められなかった。

## 注記

**調べた限りで新しいと言えそうな点**（2026 年 11 月までの文献調査、`docs/paper.ja.html` の 2.6 節）：

- 1 頂点までの距離を固定し、円が空であることを 1 つずつ証明した先行研究は見つからなかった。
- 方法と出力を確かめられる全平面の探索で、分母 10⁷ に届いたものは見つからなかった。より大きいとする掲示板の投稿は確かめられなかった。
- 箱 [−9, 10]² は正方形を含むので、結果 1b は内部も 10¹¹ まで覆う。見つかった内部の探索で最も大きいもの（Mulatram-UwU、5×10¹⁰）が、相手を列挙する考えの出典である。

個々の手法は標準的なもので、2 つの探索はどちらも有限の計算である。
