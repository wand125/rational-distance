## このコードが調べる範囲

`search.cpp` は単位正方形の **内部** `0 < x,y < 1` について、

## 必要条件とその理由

### 1. 整数化と対称性

原始な4距離解ではNは偶数です。Nが奇数なら、XとN-Xのどちらか、
YとN-Yのどちらかが奇数となり、その組の平方和がmod 4で2になってしまいます。
Nが偶数のとき、X,Yは異なる偶奇です（両方偶数は原始性に反し、両方奇数は平方和に反する）。
軸を交換し、Xを奇数にできます。平方をmod 16で調べると、YとN-Yは4の倍数です。
またmod 3で調べるとNは3の倍数です。

内部では反射によって

```
a=X odd, b=N-X odd, a<=b
c=Y multiple of 4, d=N-Y multiple of 4, c<=d
a+b=c+d=N
gcd(a,c,d)=1
```

とできます。**さらにa<cを課してはいけません。** 軸は既に偶奇で固定しています。
実装はc=dの候補も含めるため、中線の不存在定理を前提にしていません。

### 2. GOODという素因数条件

正の整数tについて、GOOD(t)を「tは奇数で、その全素因数が8で割って1または7余る」
と定義します。GOOD(1)は真、GOOD(0)は偽です。

奇素数pが8で割って3または5余るとき、2はmod pで平方非剰余です。
ある頂点の2脚がともにpの倍数なら、反対の頂点からの平方距離はmod pで2N²となります。
これが平方ならpはNも割り、gcd(X,Y,N)=1に反します。
従って各頂点の2脚の最大公約数はGOODです。

さらに、2脚r,sの和または差をpが割ると、平方距離はmod pで2r²となり、
pは両脚を割る必要があります。上の議論からこれは不可能です。
従って4頂点での脚の和・差の絶対値もGOODです。

生成した辺(a,c),(a,d)について、脚のgcdをGOODにしておけば、
|a-c|,a+c,|a-d|,a+dは自動的にGOODです。
b-c=d-a, b-d=c-aなので、残りの角で追加検査するのは
**GOOD(b+c), GOOD(b+d)** の2つだけです。

### 3. 24がNを割る

r=X-Y、s=X+Y-Nは奇数です。上の素因数条件から符号込みでr,sはmod 8で±1です。
s-r=2Y-Nは、4がY,Nを割るのでmod 8で0または4です。
一方、±1の差はmod 8で0,2,6のみです。従って8がNを割ります。
既に3がNを割るので24がNを割ります。

この議論は整数X,Yの符号に依存しません。
以上は本実装の除外条件の直接の説明であり、数学上の新規性を主張するものではありません。

## 列挙法と網羅性

まず、奇数脚aごとに、a²+e²が平方になる偶数脚eのリストL[a]を作ります。
Euclidの全ピタゴラス三つ組の表示

```
a = k(m²-n²), e = 2kmn
m>n>0, gcd(m,n)=1, m,nの偶奇は異なる
kは正の奇数でGOOD
```

を用います。a<=B/2,e<=Bとし、m²<=2Bまでで全辺を生成できます。
辺にはk=gcd(a,e)も保存します。

L[a]から2脚c,dを選べば、最初の2距離は既に整数です。
N=c+d、b=N-aとして、次を検査します。

1. 2a<=N<=B、24がNを割る。
2. gcd(a,c,d)=1。これは保存した2個のkのgcdが1かどうかで判定する。
3. GOOD(b+c),GOOD(b+d)。
4. S=b²+c²,T=b²+d²がmod 5005およびmod 215441で平方剰余。
5. S,Tがともに整数の完全平方。

5005=5×7×11×13、215441=17×19×23×29です。
平方剰余表には0も含めます。平方根は浮動小数で初期値を得ますが、
128ビット整数の乗算で上下を補正し、最後の等式判定も整数で行います。
従って浮動小数の近似を解と判定することはありません。

全ての内部4距離解は上の対称性で正規化でき、(a,c),(a,d)の両辺が必ず生成されます。
残るフィルタは必要条件なので、上限内の4距離解を取りこぼしません。

辺数をE、各リストの要素数をdeg(a)とすると、ペア生成の上界は
O(E + Σ deg(a)²)です。実装は剰余ごとの桶、ソート、二分探索により
Nの範囲外のペアを多く飛ばします。全体には素数篩と辺生成・ソートの費用も加わります。
単純な(N,X,Y)のO(B³)総当たりを実行するコードではありません。

## 条件を多く満たす点と「近傍」の意味

`candidate_example.json` と `near_100000000.csv` に、今回の剰余篩後に残った3距離点があります。

```
N = 34,112,496
X =  6,616,883
Y = 15,684,156
(x,y) ≈ (0.19397240823421424, 0.4597774375700916)
```

N倍した3距離は17,022,805、19,580,267、33,100,037です。
残りの平方距離は1,002,001,483,678,105で、これはmod 47で22となり、
平方非剰余です。従ってこの点は厳密に失格です。
多くの必要条件を満たす点が、その周りで解を見つけやすい点とは限りません。

`near_without_modular_100000000.csv` は、小さい素数の剰余篩を外した場合に
この列挙枝で見つかる45個の3距離候補です。全4距離解の探索は網羅的ですが、
この診断リストは全3距離解を網羅しません。4距離解にだけ保証される偶奇・対称性の
正規化と素因数条件を使っているためです。

平方でないSと近い平方k²の差をΔとすると、単位正方形に戻した距離の差は
|Δ| / (N(√S+k))です。大きな分母は小数上の誤差を小さくするため、
小数点以下の一致だけで候補を有望と評価することはできません。

文献上、3距離が有理数となる点は平面で稠密です。一方、特定の幾何的領域で
4距離解が見つかりやすいという根拠は確認していません。
Berryの次数2・4の3距離パラメータ族では4距離解が存在しないことも知られています。
既知の単純な族だけを高速に回す探索には、この種の落とし穴があります。

## 全平面を調べる別実装

`all_plane.cpp` は正方形の外部も含む全平面について、同じ最小共通分母の上限を
使う独立の基準実装です。内部用の高速グラフ探索とは列挙法が異なります。

```sh
g++ -O3 -std=c++17 all_plane.cpp -o all_plane
./all_plane 10000
./all_plane 1000 --validate
```

全平面では正方形の対称性によりX<=Y<=N/2とできます。
N倍した3距離をA=dist((X,Y),(0,0)), B=dist((X,Y),(N,0)),
C=dist((X,Y),(0,N))とし、p=B-A,q=C-Aと置くと、三角不等式から
0<=q<=p<=Nです。X,Yそのものには恣意的な打ち切りを設けません。

```
Q = p²+q²-N²
T = p(N²-p²)+q(N²-q²)
R = (N²-p²)²+(N²-q²)²
K = T²-QR = (N²-p²)(N²-q²)(2N²-(p-q)²)
```

3距離を実現するには4QA²-4TA+R=0が必要十分です（距離の非負性も確認します）。
Q!=0ならA=(T±√K)/(2Q)、Q=0かつT>0ならA=R/(4T)です。
Q=T=0ならR>0となり解はありません。

Kの完全平方性、割り切れること、非負の整数Aを確認した後、
X=(N²-p²-2Ap)/(2N)、Y=(N²-q²-2Aq)/(2N)を復元し、
整数座標・原始性・全距離の等式を厳密に確認します。
探索本体では4距離解の必要条件24|Nとp,qが偶数であることなどを使います。
中線や境界、二次方程式が一次方程式に退化する場合も処理しています。

| 全平面の分母上限 | (N,p,q)の組 | 原始3距離候補（4距離の必要条件を適用後） | 4距離解 | 秒 |
|---:|---:|---:|---:|---:|
| 1,000 | 1,730,651 | 152 | 0 | 0.024248 |
| 10,000 | 1,735,587,776 | 2,110 | 0 | 27.9612 |

計測は検証モードの実行時間を除きます。結果は`all_plane_result_*.json`です。
個々の実行時間は共有環境の条件により変動します。
解を発見した場合は、その証拠のJSONを行ごとに出力し、最後に統計のJSONを出力します。

組数はおよそB³/576なので、分母上限を10倍にすると約1000倍になります。
入力上限10^6は128ビット演算が安全な範囲としての制限で、現実的な計算時間の保証ではありません。

### 全平面版の検証

`--validate`では、4距離の必要条件を外してN=1..12の全ての整数3距離点を生成し、
独立した座標総当たりの集合と一致することを確認しています。合計28個の正規化された点でした。
結果を`all_plane_validation.txt`に保存しています。

総当たりに使う半径A<=2N³は証明できる上限です。
Q>0なら正の根の和T/Q<=2N³、Q<0なら正の根は√K/2<=N³/√2です。
Q=0,T>0ではp,qが正整数で、T=pq(p+q)>=p²+q²=N²、
R=p⁴+q⁴<=N⁴なのでA=R/(4T)<=N²/4です。
従って全ての場合で|X|,|Y|<=A<=2N³となります。

さらにQ=0の陽性例N=8400,p=6720,q=5040から(X,Y,A)=(164,1677,1685)
を得ることと、Q=T=0の無解例を個別に確認しています。
