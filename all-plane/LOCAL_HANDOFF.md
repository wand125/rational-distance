# ローカルへの配備・研究引き継ぎ

作成日：2026年11月5日（日本時間）。対象は単位正方形の4頂点からの有理距離問題です。

## 配備

配布ZIPを展開し、展開先の `deploy_local.py` をPython 3で実行してください。

```sh
python3 /path/to/rational_square_search/deploy_local.py
```

既定の配置先は、既存の数学研究フォルダに合わせた次の新規ディレクトリです。

```text
~/Files/03_ThinkAndPlay/WandsBox/Mathematics/RationalDistance/rational_square_search
```

変更する場合は `--destination /absolute/path` を指定します。配置先が空でない場合は停止し、既存ファイルを上書きしません。ソースのSHA-256を確認してコピーした後、ローカル用の `check`、`build`、`smoke` を順に実行します。依存パッケージのインストール、Gitへの書き込み、公開、大規模探索は実施しません。

Python 3.9以降と、C++17・C++20・128ビット整数に対応するClangまたはGCCが必要です。MacのCommand Line Toolsが未導入なら、先に端末側で開発環境を用意してください。コンパイラは `CXX` で指定できます。

配備先に `deployment_receipt.json` と `deployment.log` を作成します。receiptの `status` が `installed_and_smoke_verified` になった場合だけ、その端末でのビルドと小規模検証が完了しています。`copied_only` や `verification_incomplete` は検証完了を意味しません。

## 次に研究を進める際の候補

1. v3のgamma条件・臨界指数・正規化剰余・mod19生成時判定に加え、v4では5進条件、素数冪での射影、端点の除外、追加の臨界条件を扱います。gammaを生成へ組み込む複数の方式も比較対象です。実測の勝者と、数学的に追加された除外条件を区別し、既定値と比較用の試作を混同しないでください。
2. 除外済みの低次族を避け、未除外の族を処理する。族の不存在と有限範囲の不発見を区別する。
3. 全平面の上限2,000,000を超える実装変更では、先に `arithmetic_bounds_v2.md` の64・128ビット制約を解決する。入力上限だけを引き上げない。

これらは今後の作業候補です。配備プログラムは研究タスクや長時間探索を自動開始しません。初期のローカル受領・検証は、以前の運用に合わせて最大2ワーカー、小規模な範囲で行います。
