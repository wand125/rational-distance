# 臨界剰余マスクを4次式から直接作る方法

作成日：2026年11月5日（日本時間）。[critical_family_refinement.md](critical_family_refinement.md) の条件を、剰余ごとの一つの4次式へ整理したものです。既存ファイルは変更していません。数学的新規性や探索全体の速度向上は主張しません。

## 1. 適用範囲と正規化

前ノートと同じく、\(\ell\equiv1\pmod4\) を素数、\(s\ge1\) とし、

\[
\nu_\ell(n)=2s,\qquad \nu_\ell(\Delta)=s,\quad\Delta=u-v
\]

の枝を扱います。\(\Delta/\ell^s\) は有限体の単元なので、それで正規化し、

\[
r=\frac{u/\ell^s}{\Delta/\ell^s},\qquad
u'=r,\qquad v'=r-1
\]

と置きます。既存のgamma条件から \(r\ne0,1\) が必要です。

正規化した最初の距離を \(a\) とすると、隣接距離は \(a+2u'\)、\(a+2v'\) です。臨界パターンではある \(\iota^2=-1\) について

\[
v'(a+v')=\iota u'(a+u')
\]

が必要です。

## 2. 最初の距離を消去する

\[
d=r-1-\iota r
\]

と置くと

\[
\boxed{a=\frac{\iota r^2-(r-1)^2}{r-1-\iota r}}
\tag{1}
\]

です。\(d=0\) の場合は、分子が \((1+\iota)r^2\ne0\) になるため、元の一次方程式に解がありません。この枝は必ず除外します。

隣接する平方距離の増分は

\[
\beta=(a+2r)^2-a^2
=\frac{4r(r-1)}{d}\ne0.
\]

従って \(d\ne0\) なら、(1)は退化していない臨界パターンの最初の3距離を与えます。正規化距離の一つが0になる場合も許します。

第4距離が存在するための有限体上の条件は

\[
D'^2=a^2+4a(2r-1)+4(2r^2-2r+1)
\tag{2}
\]

の右辺が平方であることです。

## 3. 除算を使わない4次式

(1)を(2)へ代入し、\(d^2\) を掛けると

\[
\boxed{
F_\iota(r)
=4r^3-6r^2+1
-2\iota r(r-1)(r^2-r+2)
}
\tag{3}
\]

を得ます。\(t=r(r-1)\) を使えば、乗算をまとめた形は

\[
\boxed{F_\iota(r)=(2r-1)(2t-1)-2\iota t(t+2)}.
\tag{4}
\]

正確に \(F_\iota(r)=d^2D'^2\) であり、\(d^2\) は非零平方なので、臨界マスクは

\[
\boxed{r\in C_\ell
\iff \exists\iota^2=-1:
d\ne0\ \text{かつ}\ F_\iota(r)\text{ が平方}}
\]

で作れます。平方には0を含めます。**\(d=0\) の検査は省略できません。** この場合、4次式だけは分子の平方となるため、検査を省くと存在しない枝を許してしまいます。

## 4. 一方の平方根だけでよい

\[
F_\iota(1-r)=-F_{-\iota}(r),\qquad
d_{-\iota}(1-r)=-\iota d_\iota(r)
\]

です。\(-1\) は \(\mathbb F_\ell\) で平方なので、一方の \(\iota\) だけで(4)を検査し、通った \(r\) と \(1-r\) の両方を集合へ加えれば十分です。

実装は次の手順になります。

1. 全 \(a\in\mathbb F_\ell\) の \(a^2\) を使い、平方剰余表と \(\iota^2=-1\) の根を作る。
2. \(r=2,\ldots,\ell-1\) について、\(d\ne0\) と(4)の平方剰余表への所属を調べる。
3. 通った \(r\) と \(1-r\) のビットを立てる。

**逆元計算も、平方根の全符号の列挙も不要です。** 1素数あたり \(O(\ell)\) 回の有限体演算、\(O(\ell)\) の表領域で構成できます。これはビット計算量が \(O(\ell)\) という主張ではありません。

なお、既存の `critical_projection.py` の平方類を二つに正規化した方法も、場合の数は \(O(\ell)\) です。新しい式はその漸近次数を改善するものではなく、逆元・平方根の符号選択をなくし、必要な剰余 \(r\) を直接判定する整理です。独立検算用の全 \((a,b,c)\) 列挙は \(O(\ell^3)\) です。

## 5. 比較検証

`fast_critical_projection.py` は次の三方法を比較します。

- 除算なしの4次式と \(r\mapsto1-r\) の対称性。
- (1)の逆元を実際に計算し、3距離と(2)を直接検査する方法。
- 既存の平方類パターン列挙。

さらに各非退化枝で \(F_\iota(r)=d^2D'^2\) を整数の剰余計算で照合し、\(d=0\) の枝で一次方程式が不成立になることも確認します。

再実行：

```sh
python3 research_family_refinement/fast_critical_projection.py --output research_family_refinement/fast_critical_projection_certificate.json
```

既定の検証範囲は \(\ell\le257,\ \ell\equiv1\pmod4\) の全素数です。正規化距離0のケースも検証記録に含めます。

53・61の実装用64ビットマスクは、最下位ビットを剰余0として

```text
53: 0x19b742eba176cc
61: 0x1e9fedff7fdbfcbc
```

です。それより大きい素数も同じ公式で扱えますが、64ビット整数1個には収まらないので、配列などの表現を使う必要があります。平方因子を持つ分母だけで適用される条件であり、探索全体への効果は別途測定が必要です。
