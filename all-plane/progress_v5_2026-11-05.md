# 全平面探索 v5〜v8 の経過（分母 10^7 に向けて）

2026年11月5日（日本時間）、mathematics-52。
凍結版（v2・v3・v4）のソース・記録・ログは変更していない。
整数演算の上界と v5 の直し方は `arithmetic_bounds_v5.md` にある。

## 1. 版と照合

| 版 | 中身 | 照合 |
|---|---|---|
| v5（C++） | v4 の再構成を 256 ビットの正確な整数に替えた（`wide_arith_v5.hpp`） | 凍結 v4 と 1e5・2e5・2e6 で完全一致。`--no-new-filters` の 2e6 は v2 の 218 点と一致 |
| v6（Rust, `rust_v6/`） | v5 の忠実な移植（Codex に依頼、受け入れ試験は当方で実施） | C++ v5 と 2e5（1・4 スレッド）と 2e6 で完全一致 |
| v7（Rust, `rust_v7/`） | 同じ対・同じ順序のまま算術を速くした：gcd=1 の行は割り算なし、gcd>1 は行ごとに下端を 1 回分割、二進 gcd、11 素数の局所判定を行ごとのビット表に | 一辺ごとの照合（`--validate`）と、C++ v5 と 2e5・2e6 で完全一致 |
| v8（Rust, `rust_v8/`） | v7 に、11 素数の判定を分岐なしの 1 回の AND に、2・3 進の付値条件をレジスタだけで先に判定（表の参照の前） | v7 と 2e5・2e6 で完全一致、`--validate` に先行判定の全数照合を追加 |

「完全一致」は次の 3 つが同じことをいう。

- 評価に届いたパラメータ (N, p, q) の全行（`--audit-parameters`）
- 診断用の 3 距離点の全行（`--audit-three`）
- 時間を除く全カウンタ

v8 の先行判定は、付値の表 `permitted` が 0 になる条件の部分集合だけを使う。
真の値が 0 の場所でだけ早く打ち切るので、通る対もカウンタも変わらない。
この包含は `verify_small_valuation` で、n ≤ 4800 の全 x と大きな n の間引いた x で確かめた（約 270 万値）。

## 2. 速さ

同じ台・1 スレッド・分母 2e5 の探索時間（秒）。

| 版 | 母艦（M4） |
|---|---:|
| v7 | 5.17 |
| v8 | 4.78 |

分母 2e6 の全体は、v5（C++、1 本）が Intel で約 970 CPU 秒、v7 が Intel 8 スレッドで 179 秒、v8 が M1 4 スレッドで 182 秒だった。

2e5 での v7 の内訳の測定では、生成した対の 41% が 2 進・3 進の付値条件で落ちていた。
これを CRT の生成側に組み込めば生成する対は約 4 割減るが、生成の順序とカウンタが変わり、凍結版とのカウンタの照合ができなくなる。
残りの計算は数時間の規模なので、照合を保てる v8 で止めた。

## 3. 段ごとの結果

全平面、最小の座標分母 N の区間ごと。どの段も 4 距離解は 0 個である。
**全平面で、最小の座標分母が 10,000,000 以下の点に、4 頂点への距離がすべて有理数になるものはない**（11/05 11:00 に最後の段をまとめた）。これは有限の計算の結果で、存在しないことの証明ではない。

| 段 | 分母 | 版 | 区間 | 3 距離の診断点 | 4 距離解 | 結果の場所 |
|---|---|---|---:|---:|---:|---|
| 1 | 1〜2,000,000 | v4・v5（照合） | | 120 | 0 | `research_v5/`、Intel の `cmp_2000000_*` |
| 2 | 2,000,001〜4,000,000 | v5 | 48 | 107 | 0 | `sweep_v5_2000001_4000000_20261105T074833/` |
| 4 | 4,000,001〜6,000,000 | v7 | 48 | 104 | 0 | `sweep_v7_4000001_6000000_20261105T081357/` |
| 5 | 6,000,001〜8,000,000 | v8 | 48 | 97 | 0 | `sweep_v8_6000001_8000000_20261105T082607/` |
| 6 | 8,000,001〜10,000,000 | v8 | 48 | 99 | 0 | `sweep_v8_8000001_10000000_20261105T092044/` |

まとめ（`merge`）では、全区間がちょうど 1 回ずつあること、ソースのハッシュが同じこと、分母の被覆が理論上の組数と一致すること、3 距離点と 4 距離点の等式を Python の整数で検査することを確かめた。
