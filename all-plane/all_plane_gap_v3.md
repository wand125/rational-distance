# 全平面探索 v3：算術条件の強化と生成前の合同式判定

確認日：2026年11月5日（日本時間）。v1・v2と共有再構成コードは変更していません。

## 実行

```sh
g++ -O3 -std=c++17 all_plane_gap_v3.cpp -o all_plane_gap_v3
./all_plane_gap_v3 100000 --validate --audit-three three_v3.csv
```

ソース依存は同じディレクトリの `all_plane_sieved.cpp` だけです。
全平面の最小共通座標分母を指定します。入力上限は従来どおり2,000,000です。
今回のv3検証・比較は100,000までであり、v3による200万の再走は行っていません。
従来の200万完了記録は凍結したv2の記録として残ります。

既定では下記の新しい処理をすべて有効にします。比較用に個別に無効化できます。

```sh
./all_plane_gap_v3 100000 --no-field-wheel19
./all_plane_gap_v3 100000 --no-gamma --no-critical-content --no-critical-projections --no-field-wheel19
```

`--no-gamma` は共通分母条件、`--no-critical-content` は5・13での臨界指数の除外、
`--no-critical-projections` は17・29・37・41の追加剰余条件を無効にします。
従来の `--no-local`、`--no-valuation`、`--no-scale`、`--no-difference`、
`--min-denominator` も保持しています。

## 1. 数学的に追加した必要条件

記号は `n=N/2, u=(B-A)/2, v=(C-A)/2, h=u-v` です。

### 共通分母によるgamma条件

先行する和・差の分母恒等式から

\[
\gamma_n(t)=\gcd\!\left(\gcd(n,t),\frac{n}{\gcd(n,t)}\right),\qquad
\gamma_n(u)=\gamma_n(v)=\gamma_n(h)=G
\]

が必要です。さらにGの素因数は1 mod4に限られます。
出典と全平面への適用範囲は `prior_arithmetic_overlap.md` にあります。

既存のCRT・付値条件を通った組では、gammaの差が生じ得るのは、nを2回以上割る
1 mod4の素数だけです。その素数冪の積へ法を縮小してからgcdを計算します。
この縮小は追加の仮定ではなく、既存条件を使った同値な判定です。

gamma条件は、従来の12個の有限体判定と共通倍率条件をすべて通る候補にも追加の
排除力があります。例えば

\[
(n,u,v)=(16500,4035,2660),\quad h=1375
\]

では従来の条件と5・13の臨界条件を通りますが、

\[
(\gamma_n(u),\gamma_n(v),\gamma_n(h))=(5,5,1)
\]

となるため除外できます。これは整数パラメータの例であり、実際の3距離点や
4距離点を構成した例ではありません。

### 5・13での臨界指数を生成前に除外

p=5または13がGを割る場合、先行する臨界共通因子の結果から

\[
v_p(N)>2v_p(G)
\]

が必要です。従って `e=v_p(n)` が正の偶数なら、u・v・hのいずれも
`v_p(t)=e/2` にはなれません。

hに対する条件をCRT生成より前に適用することで、該当する行全体を生成しません。
u・vについては、既存の許容値配列へ同じ条件を追加します。
この結果は内部点の距離和の上界を使わず、全平面に適用できます。

### 17・29・37・41での臨界剰余条件

`v_p(n)=2s>0` かつ `v_p(h)=s` の場合は、

\[
z=(u/p^s)/(h/p^s)\pmod p
\]

が、4個の正規化した平方剰余を同時に実現できる剰余に属する必要があります。
p=17では、許されるzは `{2,4,6,8,10,12,14,16}` です。

これらの条件は、n,u,vがすべてpの倍数となって既存のmod p判定が弱くなる場合の
次の桁を調べます。許容集合は `research_family_refinement/critical_projection.py`
で完全列挙され、さらに `research_gamma/verify_v3.cpp` の独立な符号付き距離の
列挙でも一致を確認しています。

これらは既存の算術研究の結果・系を実装したもので、数学的新規性を主張しません。

## 2. mod19の判定を生成過程へ移す

従来のCRTは、固定したn,hについて uを等差数列で生成していました。
v3では `(n,h,数列の増分,u) mod19` ごとに、次に許される項までの飛び幅を
事前計算します。mod19の4距離条件を満たさない項を飛ばしてから候補を出力します。

これは既存の必要条件を生成過程へ移す変更です。新しい数学的除外条件では
ありません。出力する組の集合は「従来のCRT生成後にmod19判定した集合」と一致します。
事前表は19^4バイト、約127KiBです。

## 3. 実測結果

分母100,000、1プロセス、同じ最終v3バイナリの追加処理を無効／有効にした比較です。

| 項目 | 従来と同じ候補条件・生成 | v3既定 | 変化 |
|---|---:|---:|---:|
| 実際に生成した組 | 113,928,551 | 54,958,196 | 51.76%減 |
| 厳密再構成へ進む組 | 24,857 | 24,270 | 2.36%減 |
| 診断用の原始3距離点 | 10 | 10 | 集合も一致 |
| 4距離解 | 0 | 0 | 同じ |
| 3回の時間の中央値 | 2.01058秒 | 1.76462秒 | 時間12.23%短縮、速度1.139倍 |

共有Linux環境での値です。3組の計測では順序を交互に入れ替えました。
実測値は速度保証ではありません。記録は `research_gamma/v3_comparison.json`。

生成数の大幅な減少は主にmod19の生成過程への移動によります。
数学的に強い条件による厳密再構成対象の減少とは分けて解釈してください。
5・13のhの条件だけでは、生成数は113,928,551から111,429,951へ約2.19%減ります。

## 4. 検証

- 既存生成器との比較：全てのn=1..256でCRT集合と重複の有無を検査。
- mod19飛び幅：小範囲の全n,hで従来生成＋後段判定と集合比較。
- 新しい条件の配置：分母50,000まで、従来の全条件を通る5,399組へ新条件を
  後から直接適用した5,278組が、v3の生成・判定結果と完全一致。重複なし。
- この5,399組では、全nによるgammaと、関連素数冪だけに縮小したgammaの判定も一致。
- 臨界剰余表：5・13・17・29・37・41について独立な有限体全列挙で一致。
- 分母100,000では、残った10個の原始3距離点が凍結v2の記録と完全一致。

より強い4距離の必要条件を追加すると、別の範囲では過去の診断用3距離点を
除くことがあり得ます。診断集合の完全保存は一般的な要件ではありません。
追加条件の証明と、生成・判定集合の独立な比較が網羅性の根拠です。
